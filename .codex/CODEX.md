# Reconis 项目记忆

- 课程手册覆盖 B1–B5、A1–A10，入口见 docs/requirements-matrix.md。保留 15 张关系表、3NF、数据库过程、触发器与函数。
- SQL Server 2022 Developer + 全文组件，JDK 21、Spring Boot、MyBatis、Vue 3。业务日为北京时间，UTC 存储；金额为整数分，API 的金额和 ID 使用字符串。
- 订单明细冻结。退款按原支付锁定可退额度，外部渠道调用在短事务外，结果未知时保留预留。原始账单和历史对账结果不可变，重跑产生独立批次。
- 统计先聚合事实再关联。对账按事件键比较重复记录时保留序号；基线候选从后端按归属范围和完成状态查询，独立于当前批次列表的分页。
- MyBatis 在同一连接设置并清理会话上下文，查询始终携带授权范围。DEMO 与支付宝沙箱使用独立数据库和文件目录。凭据、数据、JAR 和备份留本机。
- Windows 使用 PowerShell 7.4+ 和项目便携 JDK。已有发布版时用独立 ReleaseId 构建，核对 /api/v1/health 后再选择默认版。
- 2026-11-04 基于远程 main 的 173f1dd，完成历史批次搜索、对账分类筛选、审计人员和结果钻取、请求关联追踪，以及页面文案与动态效果调整。
- 两份正式 PDF 留在上级课程目录，仓库保留源程序、SQL、样例、简明运行说明、数据库设计与课程要求对照。
