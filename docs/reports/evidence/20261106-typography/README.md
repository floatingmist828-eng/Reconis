# 2026年11月6日两份报告字体排版复核

## 问题定位

设计报告原有 Word 模板保留 `eastAsia="ja-JP"` 和主题字体引用。原PDF的“5.1 规范化分析示例”混用了 Calibri-Bold、MicrosoftYaHei-Bold 和 MS-Gothic；其中“范化分析示例”实际使用日文字体。正文中的“化”字码点为 U+5316，错误表现来自字体回退。同一级标题的名义字号虽然一致，混合字体仍造成字形和视觉大小不一致。

实践总结报告的正文标题已采用黑体/Arial，但模板仍有主题引用、复杂文字字号和关联字符样式的残留。两份构建器现共用显式字体与语言设置，并同步关联样式。长英文标识及多词SQL语句所在段落改为左对齐，修正两端对齐造成的异常中文字距。

## 生成方式和范围

两份最终 PDF 均由各自的 Word 文件更新目录、重新分页后导出。官方 `render_docx.py` 在本机因缺少 LibreOffice 不能运行，本次使用 Microsoft Word 导出和 pypdfium2 以140 dpi渲染逐页图片完成视觉检查。
